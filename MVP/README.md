# MVP — Photobooth Project

This folder contains the MVP (Minimum Viable Product) submission, split into two
sections covering the two halves of the build:

- [**Software**](./Software/README.md) — the background-removal photobooth
- [**Hardware**](./Hardware/README.md) — the physical enclosure, mounting, and 3D-printed components

Jump straight to the section you need:

| Section | What's in it |
|---|---|
| [Software →](./Software/README.md) | Code, dependencies, environment setup, UI flow |
| [Hardware →](./Hardware/README.md) | Enclosure design, mounting, physical build |

---

This documentation is written with the intent that someone with no prior context on this
project (a "layman") can read it top to bottom and reproduce the result from scratch.
